# Data Bridge v0.2.6 — four gaps the quality gate could not see

> Running the Confluence pipeline for real exposed defects the existing gate was structurally
> unable to catch: the space it tested was implicit and could silently disagree with production, it
> never checked the data agent's numbers, it broke citation anchors inside expand blocks, and it
> indexed content-free container pages. All four are addressed and deployed.
> 🔗 PR [#17](https://github.com/ParkHwan/Data-Bridge/pull/17)

## 1. Why

[v0.2.5](v0.2.5.md) pinned the serving space to the Confluence corpus, but the golden set kept
testing the sample one. `run_golden.py` had no notion of a space, so `ask_async` resolved
`DATABRIDGE_SPACE` to the `DEMO` default in `agents/deps.py:55` while production served `MFS`, and
every `expected_source_id` pointed at `samples/docs/*.md`. The gate was green about a configuration
production did not run.

Three more gaps surfaced alongside it. `expected_exact_value` had shipped complete in
[v0.2.3](v0.2.3.md) — schema, validators, evaluator branch — and **no golden item used it**, so the
data agent could report any figure at all. Expand blocks were rendered as blockquotes, which turns a
nested `## heading` into `> ## heading`, a form the chunker's heading regex cannot match. And pages
whose body is only a children macro were ingested as sources, each contributing a chunk whose
embedding text is mostly its own breadcrumb.

## 2. What shipped

- **A space contract for the golden set.** `space_key` is declared once at the top level (schema
  v3; v2 files keep the `DEMO` default and may not declare it). `--space` **asserts** that value
  instead of overriding it — a disagreement between the flag, the environment, or the initialized
  runtime exits before the first question is asked. Overriding silently would have recreated the
  bug being fixed. The check lives in a pure `evals/space.py` that takes the runtime lookup as an
  argument, so it stays testable without ADK.
- **The data agent's numbers are checked.** `DG-008` pins `5`; `DG-009` pins the string `"59.75"`.
  A string, because the agent reports BigQuery's full precision and an expected value rounded to
  four places is not a substring of it.
- **Expand blocks flatten.** Panels keep the quote style; `expand` and `nestedExpand` now render
  their body flat under the title, so a heading inside a disclosure still anchors a chunk.
- **Container pages are suppressed.** Detection is structural — an ADF body whose only meaningful
  node is a children macro — never a match on the rendered `[children]` text, and a test pins that
  a paragraph containing that literal string is *not* suppressed. Unlike the empty-body path from
  v0.2.5, suppressed ids are left out of `seen`, so collection removes chunks already stored. The
  check tolerates the empty trailing paragraph Confluence leaves after a macro.
- **A synthetic ADF fixture** pins the contract offline with no model in the loop: heading nesting,
  fenced code, tables at top level and inside an expand, media placeholders, inline cards, and the
  chunk heading chain that proves the expand change reaches the chunker.

## 3. Verification

**Offline gates** (`ruff`, `mypy` 33 files, `pytest`): green. The test count is
environment-dependent — with the local pgvector container running, integration tests that otherwise
skip are included, so compare like for like rather than by number alone.

**Replay of production payloads.** The real corpus was fed through `run_confluence_batch` against a
recording store: container pages suppressed, exactly their stale chunks collected, every
substantive document still ingested. This is what caught the first implementation of the container
check, which required an ADF body of exactly one node and therefore missed a real page carrying a
macro plus an empty trailing paragraph. Unit fixtures are written clean, so that shape had no
reason to appear in one.

**Live owner-run golden** (local stack, `gcp-personal` for Vertex and BigQuery): 10 of 11 items
passed. `DG-008` and `DG-009` both passed on their pinned values, confirming the string choice.
`DG-004` failed; see §6.

## 4. Process — 3-party review (Claude / Antigravity / Codex)

Design converged on this scope ahead of a semantic judge and offline CI, on the argument that a
gate whose target corpus is implicit is worth more attention than a gate that judges the right
corpus more cleverly.

Implementation review closed at zero issues in one round, both reviewers citing file and line
across nine invariants. Two findings arrived from outside that round: the container-detection
defect, found by replaying real payloads rather than by any test, and the `--set-secrets` class of
reasoning error — that verifying content survives a transform is not the same as verifying how the
next stage consumes it, which is exactly what the expand-to-blockquote defect turned on.

## 5. Production state

Merged as `3b20dac` (implementation `feb95c7`); the `^main$` build deployed revision
`databridge-00016-75j` with the ingest job on the same digest.

The first ingest on that revision (2026-07-28) suppressed four container pages and collected the
three stale chunks that had previously been stored as sources; the fourth container had never been
stored, so nothing was collected for it. Corpus figures move as the space is edited, so any single
snapshot in this note is a point-in-time reading rather than a fixed expectation.

## 6. Known limitations / deferred

- **The public golden set still targets `DEMO`.** The space contract makes the mismatch impossible
  to run into silently, but it does not by itself test the production corpus. Private `MFS` golden
  items and a deployment-drift check between the service's `DATABRIDGE_SPACE` and the ingest job's
  `SPACE_KEY` are deferred.
- **`DG-009` fails if the agent ever rounds to two places.** Observed output was full precision on
  every run, and the pinned value tolerates truncation but not rounding.
- **`DG-004` is unstable** — 4 of 9 isolated runs passed. Diagnosed in [v0.2.7](v0.2.7.md).
- Carried forward from [v0.2.4](v0.2.4.md), still open: full re-ingest each run with no incremental
  sync; `colspan`/`rowspan` flattened in Markdown; page URL and version provenance absent from the
  citation contract.
